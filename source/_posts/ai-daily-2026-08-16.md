## 今日速览

- **Meta AI**：推出全新的 Mac 桌面端应用，支持共享屏幕并基于用户屏幕内容提供内容创作与建议
- **OpenAI**：近期放缓部分 AI 开发以强化安全与防护，同时宣布对 GPT-5.6 Sol 模型 API 积分定价下调两成以上
- **Anthropic**：推出 Claude Mythos 5 漏洞扫描功能，直接接入 Claude Security 服务供企业级客户使用
- **NVIDIA**：发布 TensorRT Model Connect (TRTMC) 公开预览版，实现从 Hugging Face 检查点到原生 C++ 推理的简化
- **Google DeepMind**：发布过去 15 年游戏 AI 研究的总结博客，涵盖从 Atari 到 EVE Online 的演进
- **Google**：开源 SAM (Sovereign Agent Mesh)，提供用于 AI Agent 的零配置、零信任 P2P 网络
- **苹果**：传出 Vision 业务团队裁撤至少 60 名 VR 员工，战略重心正加速向 AI 眼镜倾斜
- **明略科技**：携手海康机器人亮相世界机器人大会，以“Agent+具身”形式切入商业机器人场景

## 重点信号

- **信息**：Anthropic 将具备网络安全攻防能力的 **Claude Mythos 5 模型**引入 Claude Security，作为公共测试版向 Enterprise 客户开放。
  **看点**：此举标志着前沿安全模型正从聊天对话向企业级基础设施深度渗透，允许企业直接连接 GitHub 仓库进行漏洞扫描而无需直接接触模型。

- **信息**：OpenAI 官方宣布在未来 3 months 内将 **GPT-5.6 Sol 模型 API 和积分定价下调 20% 以上**，并向符合条件的 ChatGPT Work 和 Codex 积分套餐开放。
  **看点**：在面临激烈市场竞争与即将到来的 IPO 节点下，大模型 API 价格战正进一步向核心前沿模型蔓延，直接降低企业与开发者的调用成本。

- **信息**：NVIDIA 推出的 **TensorRT Model Connect (TRTMC)** 项目进入公开预览，支持将 Hugging Face 检查点直接转为本地 C++ 推理。
  **看点**：该工具绕过了中间的 ONNX 导出环节，通过两行命令输出版本化的 bundle 艺术品，大幅简化了生产环境的部署门槛。

## 行业动态

- **企业端支出与模型粘性**：新数据表明 OpenAI 在企业用户增长上正在追赶 Anthropic，但客户在各家实验室推出新模型时频繁“反复横跳”的波动性，引发了投资界对**企业级 AI 支出粘性**的担忧。
- **开源与 Neoclouds 格局**：GPU Neoclouds 市场（如 CoreWeave、Nebius、Lambda、Crusoe 和 Groq）呈现出不同的商业模式分化，部分走向公开上市，部分则通过技术转型适应推理云需求。
- **具身智能与机器人落地**：在 2026 世界机器人大会上，明略科技与海康机器人联合展示了 **“Agent+具身”** 的商业服务场景落地进展。

## 技术进展

- **Agent 架构与通信**：Google 开源了 **SAM (Sovereign Agent Mesh)**，这是一个采用 Apache-2.0 协议的零配置、零信任 P2P 覆盖网络，允许自主 Agent 在多云和边缘环境中安全调用各自的 MCP 工具。
- **NVIDIA 架构研究**：NVIDIA 研究显示，通过适当的微调，即使底层 AI 模型能力一般，通过优秀的 **harness（封装架构）** 也能使 AI Agent 表现良好且保持稳定。
- **安全与零数据保留**：OpenAI 重申为符合条件的 API 客户提供 **Zero Data Retention（零数据保留）**，并预览了 Private Safety Processing 技术，在保障 AI 安全的同时保护数据隐私。

## 商业动态

- **大厂战略重心转移**：苹果 Vision 团队近期裁撤了至少 60 名 VR 开发者，其资源正向 **AI 智能眼镜** 流转，该新品预计于 2027 年 WWDC 亮相并于同年上市。
- **算力基础设施支撑**：NVIDIA 持续加大对前沿大模型实验室与数据中心基础设施的财务与生态支持。

## 观察备忘

- **模型降价与商业化压力**：API 价格的大幅下调和激烈的产品迭代，折射出头部大模型厂商在商业化变现与市场占有率之间的博弈加剧。
- **Agent 落地从概念转向网络化**：随着 Google SAM 等 P2P 基础设施的出现，Agent 之间的互联互通和零信任协同正成为新的技术基建方向。
- **安全边界与合规挑战**：前沿模型在网络安全漏洞扫描（如 Claude Mythos 5）与生成边界控制（如内容限制测试）上面临双重考验，安全治理正成为企业客户评估核心供应商的关键指标。
